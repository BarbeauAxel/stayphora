# Scènes 3D locales (développement)

Ce dossier n'est **pas** versionné ni déployé (voir `.gitignore` et `public/.assetsignore`).
En production, les scènes sont servies depuis le bucket R2 (`NEXT_PUBLIC_ASSETS_URL`).

Arborescence attendue (identique aux clés du bucket R2) :

```
public/demo/tours/appartement.spz
public/demo/tours/appartement-mobile.spz
public/demo/tours/riverview.spz
public/demo/tours/riverview-mobile.spz
```

Les scènes d'exemple proviennent du jeu de données Eyeful Tower (Meta, licence MIT) ;
voir `licences/` et le README principal.
